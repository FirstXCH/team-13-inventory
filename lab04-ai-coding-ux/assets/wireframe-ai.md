**จัดทำโดย**: Team 13  
**หลักการออกแบบ**: รองรับ Persona พนักงานคลังสินค้า และสอดคล้องกับมาตรฐานการเข้าถึง WCAG 2.1 (AA)

---

## 1. หน้าจอเข้าสู่ระบบ (Login Screen)
```text
+-----------------------------------------------------------------------+
|  SMART INVENTORY MANAGEMENT SYSTEM - TEAM 13                          |
+-----------------------------------------------------------------------+
|                                                                       |
|                         [ สัญลักษณ์ระบบคลัง ]                         |
|                       เข้าสู่ระบบจัดการสินค้า                         |
|                                                                       |
|   ชื่อผู้ใช้งาน / Username *                                          |
|   +---------------------------------------------------------------+   |
|   | somchai.m                                                     |   |
|   +---------------------------------------------------------------+   |
|                                                                       |
|   รหัสผ่าน / Password *                                               |
|   +---------------------------------------------------+-----------+   |
|   | ******************                                | [👁️ แสดง]  |   |
|   +---------------------------------------------------+-----------+   |
|                                                                       |
|   [⚠️ ข้อความแจ้งเตือน: รหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบแป้นพิมพ์ Caps Lock ] |
|                                                                       |
|   +---------------------------------------------------------------+   |
|   |                 [ ปุ่ม: เข้าสู่ระบบ (Primary) ]               |   |
|   +---------------------------------------------------------------+   |
|                                                                       |
+-----------------------------------------------------------------------+
```
* **Usability & Accessibility**:
  * มี Label ชัดเจนด้านบน ไม่ใช้ Placeholder แทน Label
  * ดอกจัน `*` ระบุชัดเจนว่าเป็นช่องที่บังคับกรอก (Required)
  * ปุ่ม "เข้าสู่ระบบ" มีขนาดใหญ่เต็มความกว้าง (Min height 48px) กดง่ายบนจอสัมผัส
  * กล่องแจ้งเตือน Error แสดงทั้งไอคอนเตือน `⚠️` และข้อความแนะนำวิธีแก้ไขอย่างสุภาพ

## 2. หน้าจอแดชบอร์ดคลังสินค้า (Dashboard Screen)
```text
+-----------------------------------------------------------------------+
| [ระบบคลัง Team 13]  | หน้าหลัก | รายการสินค้า | [คุณสมชาย (เจ้าหน้าที่)] [ออกจากระบบ] |
+-----------------------------------------------------------------------+
|                                                                       |
|  [ สรุปยอดสินค้าในคลัง ]        [ สินค้าสต็อกต่ำเตือนด่วน ]           |
|  +------------------------+    +----------------------------------+   |
|  | ทั้งหมด: 45 รายการ     |    | ⚠️ รอสั่งเพิ่ม: 3 รายการ         |   |
|  +------------------------+    +----------------------------------+   |
|                                                                       |
|  +-----------------------------------------------------------------+  |
|  | [ + ปุ่มหลัก: บันทึกสินค้าใหม่ ]   [ ⬇️ ส่งออกรายงาน Excel ]     |  |
|  +-----------------------------------------------------------------+  |
|                                                                       |
|  ตาราง: รายการสินค้าที่ต้องตรวจนับสต็อก                               |
|  +----------+----------------------+---------+----------+----------+  |
|  | รหัส     | ชื่อสินค้า           | ประเภท  | คงเหลือ  | สถานะ    |  |
|  +----------+----------------------+---------+----------+----------+  |
|  | BOOK-P01 | คู่มือ Database เล่ม | เล่มจริง| 2 เล่ม   | [⚠️ สต็อกต่ำ] |
|  | BOOK-P02 | นวนิยายปกแข็ง        | เล่มจริง| 1 เล่ม   | [⚠️ สต็อกต่ำ] |
|  | EBOOK-D1 | Building Calm (PDF)  | ดิจิทัล | ไม่จำกัด | [✅ ปกติ]  |
|  +----------+----------------------+---------+----------+----------+  |
|                                                                       |
+-----------------------------------------------------------------------+
```
* **Usability & Accessibility**:
  * แสดงแท็กประเภทสินค้า "เล่มจริง" กับ "ดิจิทัล" แยกกันชัดเจน
  * สถานะสต็อกต่ำมีทั้งสัญลักษณ์ `⚠️` และข้อความ `[สต็อกต่ำ]` ป้องกันปัญหาคนตาบอดสี
  * ปุ่ม Action หลัก "บันทึกสินค้าใหม่" ใช้สีเด่นชัดเจน

## 3. หน้าจอเพิ่มสินค้าใหม่เข้าคลัง (Add Product Screen)
```text
+-----------------------------------------------------------------------+
| [ระบบคลัง Team 13]  < กลับหน้ารายการสินค้า                            |
+-----------------------------------------------------------------------+
|                                                                       |
|  แบบฟอร์มบันทึกสินค้าใหม่                                             |
|                                                                       |
|  เลือกประเภทสินค้าที่ต้องการเพิ่ม *                                   |
|  ( ) สินค้าเล่มจริง (Physical)       ( ) สินค้าดิจิทัล (E-Book/PDF)   |
|  -------------------------------------------------------------------  |
|                                                                       |
|  รหัสสินค้า (Product ID) *                                            |
|  [ BOOK-P04                                                         ] |
|                                                                       |
|  ชื่อสินค้า (Product Name) *                                          |
|  [ หลักการวิศวกรรมซอฟต์แวร์ เล่ม 1                                  ] |
|                                                                       |
|  ราคาขาย (บาท) *                                                      |
|  [ 350.00                                                           ] |
|                                                                       |
|  จำนวนสต็อกเริ่มต้น *            เกณฑ์เตือนสต็อกต่ำ (Threshold) *     |
|  [ - ] [ 10 ] [ + ]              [ 3 ]                                |
|                                                                       |
|  +-----------------------------------------------------------------+  |
|  | [ ปุ่มหลัก: ยืนยันบันทึกสินค้าเข้าคลัง ]  [ ปุ่มรอง: ยกเลิกและล้างค่า ] |
|  +-----------------------------------------------------------------+  |
|                                                                       |
+-----------------------------------------------------------------------+
```
* **Usability & Accessibility**:
  * มีปุ่ม `[ - ]` และ `[ + ]` ขนาดใหญ่ ช่วยให้พนักงานจิ้มเพิ่ม-ลดจำนวนได้ทันทีบนจอสัมผัส
  * ปุ่มยืนยันระบุชื่อชัดเจนว่า "ยืนยันบันทึกสินค้าเข้าคลัง" แทนคำว่า "OK" หรือ "Save"
  * ลำดับการกดปุ่ม Tab เป็นไปตามแนวตั้งจากบนลงล่างอย่างเป็นธรรมชาติ
