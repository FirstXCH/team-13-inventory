# Spec: ระบบจัดการคลังสินค้า (Inventory System) สำหรับร้านค้าทั่วไปและร้านหนังสือดิจิทัล

## 1. เป้าหมาย (Goal)
พัฒนาระบบคลังสินค้าที่รองรับสินค้า 2 ชนิดตามข้อกำหนดวิชาวิศวกรรมซอฟต์แวร์ (ประกาศ 11 ก.ย. 2569):
1. **สินค้าที่จับต้องได้ (Physical Goods)**: มีสต็อกจริง ต้องตัดยอดคงเหลือ และห้ามสั่งซื้อเกินจำนวนที่มี
2. **สินค้าดิจิทัล (Digital Goods / E-Books)**: ไม่มียอดคงเหลือให้ตัด (ขายได้ไม่จำกัด) แต่ต้องควบคุมสิทธิ์การเข้าถึงไฟล์ดาวน์โหลด

## 2. ขอบเขตของระบบ (System Scope)
- **อยู่ในขอบเขต (In-Scope)**:
  - จัดการข้อมูลสินค้า แคตตาล็อก หมวดหมู่ ราคา และสถานะพร้อมขาย (`is_active`)
  - จัดการสต็อกสินค้ากายภาพ และระบบแจ้งเตือนสินค้าใกล้หมด (Low Stock Alert ผ่าน Observer Pattern)
  - จัดการกฎธุรกิจสินค้าดิจิทัล (ตรวจสอบสถานะคำสั่งซื้อก่อนเปิดสิทธิ์ดาวน์โหลด)
- **อยู่นอกขอบเขต (Out-of-Scope)**:
  - ระบบเกตเวย์ชำระเงินจริง (Payment Gateway Webhook)
  - การจัดการฐานข้อมูลเชิงสัมพันธ์ระดับ 3NF (ยกยอดไปทำในวิชา Database: BookSell-DatabaseProject)

## 3. User Stories
| รหัส | User Story |
|---|---|
| US-01 | As a พนักงานคลังสินค้า, I want to บันทึกรับ/เบิกสินค้ากายภาพ, so that ยอดสต็อกตรงกับความเป็นจริง |
| US-02 | As a ผู้จัดการ, I want to ได้รับการแจ้งเตือนเมื่อสินค้ากายภาพต่ำกว่า threshold, so that สามารถสั่งซื้อเพิ่มได้ทันเวลา |
| US-03 | As a ผู้ดูแลระบบ, I want to ปิดการขายสินค้าที่ไม่พร้อมจำหน่าย, so that หน้าร้านไม่แสดงรายการนั้น |
| US-04 | As a ลูกค้าที่ซื้อสินค้าดิจิทัล (E-Book), I want to ดาวน์โหลดไฟล์ได้เฉพาะเมื่อคำสั่งซื้อได้รับการยืนยัน (Confirmed) แล้วเท่านั้น, so that มั่นใจในความปลอดภัยของระบบ |

## 4. Acceptance Criteria (Given-When-Then)

### AC ของ US-04 (สินค้าดิจิทัลและสิทธิ์ดาวน์โหลด)
```gherkin
Scenario: คำสั่งซื้อยังไม่ยืนยัน (Pending) จะไม่ได้รับลิงก์ดาวน์โหลด
  Given มีหนังสือดิจิทัลรหัส "EBOOK-D02" อยู่ในระบบ
  When ลูกค้าสั่งซื้อหนังสือแต่สถานะคำสั่งซื้อเป็น "Pending"
  Then ระบบต้องไม่อนุญาตให้ดาวน์โหลดไฟล์ (download_unlocked = False)
  And ลิงก์ดาวน์โหลดต้องเป็น None

Scenario: คำสั่งซื้อยืนยันแล้ว (Confirmed) จะได้รับลิงก์ดาวน์โหลดทันที
  Given มีหนังสือดิจิทัลรหัส "EBOOK-D02" อยู่ในระบบ
  When ลูกค้าชำระเงินและคำสั่งซื้อเปลี่ยนสถานะเป็น "Confirmed"
  Then ระบบต้องปลดล็อกสิทธิ์ดาวน์โหลด (download_unlocked = True)
  And ระบบส่งมอบลิงก์ดาวน์โหลดไฟล์ที่ถูกต้อง
```
