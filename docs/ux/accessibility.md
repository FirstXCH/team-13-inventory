# Accessibility Audit Report (ผลการตรวจความเข้าถึงตามเกณฑ์ WCAG 2.1)

จากการตรวจประเมินส่วนต่อประสานผู้ใช้ ทีมได้พบจุดที่ต้องปรับปรุงและดำเนินการแก้ไขเป็นข้อๆ ดังนี้:

| จุดที่ตรวจพบ | ปัญหาตามเกณฑ์ WCAG | การแก้ไขที่ดำเนินการ |
|---|---|---|
| 1. ปุ่มยืนยันและสวิตช์สถานะ | Contrast Ratio ต่ำกว่า 4.5:1 (ตัวอักษรกลืนกับพื้นหลัง) | ปรับใช้คู่สี high contrast ที่อัตราส่วน 7.2:1 ตามเกณฑ์ระดับ AAA |
| 2. ฟิลด์กรอกจำนวนสินค้า | ไม่มีป้ายกำกับ aria-label หรือ label ที่ชัดเจน | เพิ่ม `<label htmlFor="qty">` และระบุ `aria-describedby` ให้ Screen Reader อ่านได้ |
| 3. ไอคอนแจ้งเตือนสถานะ | สื่อความหมายด้วยสีเพียงอย่างเดียว (Color-only indicator) | เพิ่มข้อความกำกับสถานะ (Text badge) ควบคู่กับไอคอน เช่น "พร้อมขาย" / "ปิดการขาย" |
| 4. การควบคุมด้วยคีย์บอร์ด | โฟกัสไม่แสดงเส้นกรอบเมื่อกด Tab | เพิ่ม CSS `:focus-visible` มี outline ชัดเจนหนา 2px สี Accent ชัดเจน |
