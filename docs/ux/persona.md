# User Personas: ระบบคลังสินค้า Inventory System

## 1. Persona 1: สมศักดิ์ (ผู้จัดการคลังสินค้า - Warehouse Manager)
- **ข้อมูลประชากร**: อายุ 42 ปี ทำงานด้าน Logistics & Inventory มา 15 ปี
- **เป้าหมาย (Goals)**:
  - ต้องการเห็นภาพรวมสต็อกสินค้ากายภาพแบบทันที
  - ต้องการระบบเตือนเมื่อสินค้าใกล้หมดเพื่อสั่งผลิต/สั่งซื้อเติมสต็อกได้ทันท่วงที
- **ความกังวล (Frustrations)**:
  - กลัวระบบยอมให้ลูกค้ากดสั่งซื้อเกินจำนวนที่มีจริงในคลัง (Overselling)

## 2. Persona 2: นิศา (แอดมินร้านค้าออนไลน์ - Store Admin)
- **ข้อมูลประชากร**: อายุ 27 ปี ดูแลการลงรายการสินค้าทั้งหนังสือเล่มและ E-Book
- **เป้าหมาย (Goals)**:
  - ต้องการปิดการขายหนังสือที่ติดลิขสิทธิ์หรือยังไม่ออกจำหน่ายชั่วคราวได้ในคลิกเดียว
  - ตรวจสอบรายการสั่งซื้อและกดยืนยันการชำระเงินเพื่อให้ระบบปลดล็อกไฟล์ E-Book ให้ลูกค้า
